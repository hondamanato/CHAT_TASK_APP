# AIチャットに会話履歴認識機能を追加 (2025-10-18)

## 問題
AIが前の会話を認識せず、毎回独立したメッセージとして処理していた。

**例（問題のある会話）:**
1. ユーザー: 「来週病院」
2. AI: 「来週の何曜日ですか？」
3. ユーザー: 「火曜」
4. AI: 「火曜日について何かご予定がありますか？」← 「来週病院」を覚えていない

## 原因
`ChatScreen.tsx`の`sendMessage`関数が、現在のメッセージのみをAIに送信し、過去の会話履歴を渡していなかった。

## 修正内容

### 完了した作業
- [x] `ChatScreen.tsx`で会話履歴を構築してAIに渡す機能を追加
  - 直近10メッセージ（5往復分）を取得
  - 「ユーザー: [メッセージ]」「AI: [メッセージ]」形式で履歴文字列を作成
  - `processChatMessage`の第2引数`context`に会話履歴を渡す

### 変更ファイル
**src/components/ChatScreen.tsx** (L139-148)
```typescript
// 会話履歴を構築（直近5往復=10メッセージ）
const recentMessages = messages.slice(-10);
const conversationHistory = recentMessages
  .map(msg => `${msg.isUser ? 'ユーザー' : 'AI'}: ${msg.text}`)
  .join('\n');

const response = await hybridAIService.processChatMessage(
  inputText.trim(),
  conversationHistory // 会話履歴をコンテキストとして渡す
);
```

## 期待される効果

### その他の改善
- 予定の詳細を段階的に確認できる
- より自然な会話体験
- ユーザーが情報を繰り返す必要がない


# スプラッシュスクリーンで止まる問題の修正 (2025-10-18)

## 問題
- アプリの初回起動時などに青いスプラッシュスクリーン(Taplessロゴ)のまま止まって画面が切り替わらない
- 一度アプリを閉じてもう一度開くとカレンダー画面が正常に表示される

## 原因
1. **AuthContext**: `initializeAuth`でSupabaseセッション取得が完了しないと`loading`が`true`のまま
   - ネットワーク遅延やタイムアウトで無限待機が発生
   - プロフィール取得処理も待機してブロック

2. **LocalizationContext**: `loadLocale`関数の非同期処理が完了を保証していない
   - `Localization.getLocales()`の取得に時間がかかる場合がある

3. **複数Contextのネスト**: AuthProvider、LocalizationProvider等が順番にマウント
   - どれか1つでも初期化が遅延すると全体が遅延

## 修正内容

### 完了した作業
- [x] AuthContextに10秒のタイムアウト処理を追加
  - `Promise.race()`でセッション取得とタイムアウトを競争
  - タイムアウト時はログを出力してスキップ
  - プロフィール取得を非同期化してブロックしない
  - クリーンアップ処理でタイムアウトをクリア

- [x] LocalizationContextに3秒のタイムアウト処理を追加
  - ロケール読み込みが遅延してもデフォルト(ja)で続行
  - 初期化完了フラグ(`isInitialized`)を追加

### 変更ファイル
- `src/contexts/AuthContext.tsx`: L76-170
  - タイムアウト処理とエラーハンドリングを強化
- `src/contexts/LocalizationContext.tsx`: L16-37
  - タイムアウト処理を追加

## 期待される効果
- 初回起動時のスプラッシュスクリーン停止問題が解消
- ネットワーク遅延時でも最大10秒でメイン画面に遷移
- オフラインモードでもスムーズに起動

## レビュー
- AuthContextのセッション取得をタイムアウト付きに変更し、ブロッキングを回避
- LocalizationContextのロケール読み込みもタイムアウト保護を追加
- エラーハンドリングとログ出力を強化して問題追跡を容易化
- どちらのContextも最終的に必ず`loading`状態を解除するようになり、画面遷移が保証される
