利用規約

English

最終更新日: 2026年10月6日

本利用規約（以下「本規約」）は、Tapless（以下「本アプリ」）の提供者（以下「当方」）と利用者との間の、本アプリの利用条件を定めるものです。本アプリを利用することで、本規約とプライバシーポリシーに同意したものとみなします。

1. サービスの内容

本アプリは、予定の管理と、AIを用いた予定の作成・編集を支援するカレンダーアプリです。カレンダーの共有、通知、ウィジェット、天気と祝日の表示、写真からの予定の読み取りなどの機能を提供します。

2. アカウント

  • 本アプリの利用にはアカウントの登録が必要です。メールアドレスとパスワード、またはAppleでサインインで登録できます
  • 登録情報は正確なものを入力してください。パスワードなどの管理は利用者の責任で行ってください
  • アカウントを第三者に譲渡・貸与することはできません
  • アカウントはいつでもアプリ内から削除できます。削除した情報は復元できません
  • 本アプリは13歳未満の方の利用を想定していません

3. Tapless Plus（サブスクリプション）

  • 本アプリは、無料で利用できる範囲と、月額または年額のサブスクリプション「Tapless Plus」を提供します
  • 無料プランには、AIによる予定作成の回数、写真の読み取り枚数、天気の表示日数、共有できる人数などの上限があります
  • Tapless Plusにも、AIによる予定作成の回数と写真の読み取り枚数に月ごとの上限があります。上限は毎月1日の午前9時（日本時間。協定世界時の0時）にリセットされます
  • 各プランの具体的な数値は、アプリ内の購入画面に表示します
  • 料金はApp Storeに表示される価格に従い、Apple IDに請求されます
  • サブスクリプションは、期間終了の24時間前までに解約しない限り自動的に更新されます
  • 解約は、iOSの「設定」→ Apple ID →「サブスクリプション」から行えます。アプリ内の購入画面からも同じ場所へ移動できます
  • アカウントやアプリを削除してもサブスクリプションは解約されません。解約する場合は、削除の前にAppleのサブスクリプション管理で手続きしてください
  • 無料トライアルが提供される場合、未使用の期間はサブスクリプションを購入した時点で失効します
  • 返金はAppleの規定に従います。当方は返金の可否を決定できません
  • 上限の数値や提供する機能は、変更する場合があります。利用者に不利な変更を行う場合は、事前にアプリ内などでお知らせします

4. AI機能

  • AI機能では、入力した文章や写真、関連する予定などを、米国のGoogle LLCが提供するGemini APIへ送信します。Googleは送信された内容を自社の製品の改善などに利用し、人が内容を確認する場合があります。詳しくはプライバシーポリシー第3項をご確認ください。AI機能を利用することで、この取り扱いに同意したものとみなします
  • 他人に見られて困る情報（健康や病歴、金融の情報、パスワードなど）をAI機能に入力・送信しないでください
  • 他人の氏名などが写った写真（シフト表など）を送る場合は、利用者の責任で、必要な範囲にとどめてください
  • AIは入力内容を解釈して予定を作成・変更しますが、常に正しい結果になるとは限りません。作成・変更された予定は、利用者自身で確認してください
  • AIの解釈の誤りによって生じた予定の重複、欠落、誤りについて、当方は第8項の範囲でのみ責任を負います
  • 不正利用と過剰な利用を防ぐため、プランの上限とは別に、短時間の大量送信、1日あたりの通信回数、1回の送信量と応答量を制限します。この制限はTapless Plusにも適用されます
  • AI機能は外部のサービスを利用しているため、その提供状況により一時的に利用できない場合があります

5. 共有カレンダー

  • 共有カレンダーの参加者には、あなたの表示名、プロフィール画像、そのカレンダーに入れた予定が表示されます
  • 招待リンクは、参加させたい相手にだけ渡してください。リンクを受け取った人は、有効期限内であれば参加できます
  • 共有カレンダーに入れる内容は、ほかの参加者に見られることを前提に、利用者の責任で入力してください

6. 禁止事項

  • 法令または公序良俗に反する行為
  • 他の利用者または第三者の権利、プライバシー、名誉を侵害する行為
  • 他人になりすます行為、他人のアカウントを利用する行為
  • 本アプリやサーバーへの不正アクセス、過度な負荷をかける行為、自動化した手段による大量の送信
  • 利用上限や課金を回避しようとする行為
  • 本アプリを逆コンパイル、改変して利用する行為
  • AI機能を、予定の管理と関係のない目的に利用する行為

当方は、利用者が本規約に違反した場合、事前の通知なく機能の利用を制限し、またはアカウントを停止することがあります。
