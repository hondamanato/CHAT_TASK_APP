プライバシーポリシー

最終更新日: 2025年1月1日

1. 収集する情報

当社は、本サービスの提供のため、以下の情報を収集します：

1.1 アカウント情報

  • メールアドレス
  • パスワード（暗号化して保存）
  • ユーザー名

1.2 カレンダーデータ

  • イベント情報
  • スケジュール詳細
  • 設定データ

1.3 使用状況に関する情報

  • アプリの使用履歴
  • 機能利用状況
  • エラーログ

1.4 デバイス情報

  • デバイスの種類
  • OS バージョン
  • アプリのバージョン
  • 一意のデバイス識別子

1.5 カメラ・写真データ

  • プロフィール画像
  • チャット機能で送信される画像
  • 画像のメタデータ（撮影日時、位置情報等）

1.6 位置情報

  • イベント作成時の場所検索履歴
  • Google Places API を通じて取得される場所データ
  • 位置に基づく場所候補の提供

1.7 通知関連情報

  • プッシュ通知の設定
  • 通知の配信履歴
  • 通知の開封状況

1.8 チャット・AI機能関連データ

  • AIチャットの会話履歴
  • ユーザーからの質問内容
  • AI応答の学習データ（個人を特定しない形で）

1.9 ローカルストレージデータ

  • アプリ設定情報
  • オフライン利用時の一時データ
  • ユーザー設定の保存情報

2. 情報の利用目的

収集した情報は以下の目的で利用します：

2.1 サービス提供のため

  • アカウント管理
  • カレンダー機能の提供
  • AI による予定分析・提案
  • プロフィール画像の表示・管理
  • チャット機能での画像表示
  • 位置情報に基づく場所候補の提供
  • プッシュ通知の配信
  • オフライン機能の提供

2.2 サービス改善のため

  • 機能の最適化
  • バグの修正
  • 新機能の開発
  • AIチャット機能の性能向上
  • 位置情報検索精度の向上

2.3 ユーザーサポートのため

  • お問い合わせへの回答
  • 技術的な問題の解決
  • 使用方法のガイダンス

2.4 セキュリティ確保のため

  • 不正アクセスの防止
  • システムの安全性維持
  • セキュリティ監査

3. 情報の第三者提供

当社は、以下の場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません：

3.1 法令に基づく場合

  • 法令の規定に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合
  • 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合

3.2 業務委託の場合

  • 個人情報の取扱いを委託する場合（適切な監督を行います）

4. 情報の保存期間

個人情報は、利用目的が達成される期間、または法令で定められた期間保存します。

5. 情報の管理

当社は、収集した個人情報について、適切な安全管理措置を講じ、不正アクセス、漏洩、滅失または毀損の防止に努めます。

6. ユーザーの権利

ユーザーは、自己の個人情報について以下の権利を有します：

  • 開示請求権
  • 訂正・追加・削除請求権
  • 利用停止・消去請求権
  • 第三者提供停止請求権

7. Cookie について

本サービスでは、より良いユーザーエクスペリエンスを提供するため、Cookie を使用する場合があります。

8. 外部サービスとの連携

本サービスは、以下の外部サービスと連携する場合があります：

  • Google Calendar API（祝日・カレンダー情報の取得）
  • Google Places API（位置情報・場所検索）
  • AI分析サービス（Gemini AI、OpenAI等）
  • 通知サービス（Expo Notifications）
  • Supabase（データベース・認証）

これらの外部サービスにおける個人情報の取扱いについては、各サービスのプライバシーポリシーをご確認ください。

9. 権限の取得と利用

本サービスでは、以下の権限を取得する場合があります：

  • カメラアクセス権限：プロフィール画像撮影、チャット画像撮影のため
  • 写真ライブラリアクセス権限：プロフィール画像選択、チャット画像選択のため
  • 位置情報アクセス権限：場所検索機能の提供のため（任意）
  • 通知権限：プッシュ通知配信のため

これらの権限は、該当機能を使用する際にユーザーの同意を得て取得します。

10. 国際データ転送

本サービスでは、サービス向上のため、個人情報を適切な安全管理措置の下で国外に転送する場合があります。

11. 未成年者の個人情報

13歳未満のお客様の個人情報を収集する場合、保護者の同意を得るものとします。

12. プライバシーポリシーの変更

当社は、本プライバシーポリシーを変更する場合があります。重要な変更については、サービス内での通知等により、ユーザーにお知らせします。
